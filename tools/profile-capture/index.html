Obscura profile capture

Open this page in the real Chrome whose signature you want, ideally a clean profile that isn't signed in, on the network the crawler will use. It reads only what that browser reports about itself and sends nothing anywhere. Save the result as the file OBSCURA_PROFILE_FILE points to.

Serve it from http://localhost (for example python3 -m http.server in this folder) so Chrome exposes its client hints.
